# Ghummakad Manav Single Page Website

Static GitHub Pages site for the Ghummakad Manav travel channel and 12 Jyotirlinga solo road-trip plan.

## Files

- `index.html` - single page website
- `styles.css` - responsive layout and visual design
- `app.js` - mobile navigation and YouTube video carousel
- `assets/` - provided map, QR codes, and channel profile image

## GitHub Pages

Push this repository to GitHub, then enable Pages from the repository settings using the `main` branch and root folder.
